# prilepsketrziste.eu

Web Přílepského procházkového adventního tržiště. Čistě statický web (HTML + CSS), nasazuje ho Netlify automaticky po každé změně v této větvi `main`.

- `index.html` – hlavní stránka (texty, formulář, mapa)
- `dekujeme.html` – stránka po odeslání registrace
- `styles.css` – vzhled
- `img/` – fotky a znak obce
- Registrace přijímá Netlify Forms (formulář `registrace`).
